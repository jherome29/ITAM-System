# Frontend Prototype Deferred Backend Work

This phase is frontend-only. The proposed role model, navigation visibility, mock actions, and read-only states are presentation logic only and are not secure enforcement.

Deferred backend and database work:

- Database role migration.
- New backend roles.
- Backend asset-type authorization.
- Backend approval routing.
- Backend self-approval enforcement.
- Backend record-level authorization.
- Backend transactional fulfillment.
- Backend disposal approval.
- Backend organizational-unit scope.
- Backend custodian scope.
- Real QR hardware integration.
- Real file upload.
- Real PDF generation changes.
- Real notification delivery.
- Real audit persistence.

Current mock workflows use typed fixtures, frontend state, dialogs, and toast messages. They must be replaced or backed by authenticated backend endpoints before production use.
